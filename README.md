                                                         Excel Sales Analysis – Product Sales Dashboard

**Project Overview**

This project focuses on analysing approximately 1,500 product sales records using Microsoft Excel.

The objective was to explore sales performance, identify patterns, compare business performance across different categories and regions, and present the findings through an interactive Excel dashboard.

This project was completed as part of my self-directed learning journey in Data Analytics, with the aim of developing practical Excel skills and understanding how data can support business decision-making.

**Objectives**

The main objectives of this project were:

- Clean and organise raw sales data.
- Analyse product and regional sales performance.
- Identify sales trends and patterns.
- Compare discounted and non-discounted sales.
- Examine product returns and promotion effectiveness.
- Create visualisations to communicate findings.
- Develop an interactive Excel dashboard.

**Dataset**

- Dataset: Product Sales Dataset
- Number of Records: Approximately 1,500
- Format: Excel Workbook (.xlsx)

The dataset was downloaded for educational and analytical practice. The original download source is currently unidentified.

**Tools & Excel Features Used**

- Microsoft Excel

- Excel Functions

- Conditional Formatting
- Data Visualisation
- Interactive Dashboard

**Analysis Performed**

The project explored the following business questions:

1. Monthly Sales Analysis: Which month recorded the highest sales?

2. Product Performance: Which products generated the highest sales?

3. Staff and Regional Analysis: How did staff workload or performance vary across regions?

4. Discount Analysis: How did sales compare between customers who received discounts and those who did not?

5. Regional Performance: Which were the top three regions based on sales?

6. Selling Method Analysis: Which selling method generated the highest sales?

7. Product Returns: Which product had the highest number of returns?

8. Promotion Effectiveness: How effective were promotions in generating sales?

**Dashboard**

An interactive Excel dashboard was created to bring together the key analysis and visualisations.

The dashboard includes six charts to help explore sales performance, product trends, regional comparisons and other business metrics.

Key Learning Outcomes

Through this project, I gained practical experience in:

- Preparing and organising sales datasets.
- Applying Excel features to analyse business data.
- Using PivotTables to summarise large datasets.
- Creating charts to communicate analytical findings.
- Building an interactive dashboard.
- Understanding how data analysis can help answer business questions.
